IMPORTANT
- Upload the CONTENTS inside the extracted production folder, not the ZIP file.
- Do not upload the outer folder itself.
- Do not delete the existing wrangler.jsonc or CNAME files in GitHub.
- Use the main branch because it is the production branch for this project.

STEP 1 — DOWNLOAD AND EXTRACT
1. Download OCD_Services_v70_FINAL_PRODUCTION_AUDITED_20260729_2358.zip.
2. Open your Downloads folder.
3. Right-click the ZIP and select Extract All.
4. Open the extracted folder.
5. You should immediately see index.html, assets, robots.txt, sitemap.xml and the six service-page folders.

STEP 2 — OPEN GITHUB
1. Open:
   https://github.com/ocdservicesuk-collab/ocd-services-preston
2. Check that the branch selector shows main.
3. Select Add file.
4. Select Upload files.

STEP 3 — UPLOAD THE WEBSITE
1. Return to the extracted production folder.
2. Select everything INSIDE the folder:
   - index.html
   - assets
   - all six service-page folders
   - robots.txt
   - sitemap.xml
   - sitemap.txt
   - site.webmanifest
   - favicon files
   - _headers
   - Google verification file
3. Drag the selected contents onto the GitHub upload page.
4. Wait for GitHub to finish listing the uploaded files.
5. Do not remove wrangler.jsonc or CNAME if they already exist in the repository.

STEP 4 — COMMIT TO PRODUCTION
1. Enter:
   Deploy OCD Services v70 final production
2. Select Commit directly to the main branch.
3. Select Commit changes.

STEP 5 — CHECK CLOUDFLARE
1. Open:
   https://dash.cloudflare.com/
2. Go to Workers & Pages.
3. Open ocd-services-preston.
4. Open Deployments.
5. Wait for the newest deployment from main to show success.
6. Cloudflare automatically builds and deploys pushes to the configured production branch.

STEP 6 — CHECK PREVIEW AND LIVE SITE
Open:
https://ocd-services-preston.ocd-services-uk.workers.dev/

Then open:
https://ocdservicespreston.co.uk/
